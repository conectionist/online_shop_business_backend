Implementing a new entity is a complex task! The process is prone to error if not done correctly and in a rushed way. 
To ensure success, we will always use a "baby steps" approach (i.e. one step at a time).
That means Cascade will perform a step then wait for the user to give feedback. 
If the user wants changes, Cascade will implement them. 
If not, the user will give Cascade the green light to move to the next step.
Cascade will make an effort to actually stick to this (baby step) approach until the end. It will not get ahead of itself and start implementing multiple steps at a time halfway though. 

Remember: implement step --> get feedback --> apply feedback (if necessary) --> get green light --> implement next step.
