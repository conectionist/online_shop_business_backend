The website I want will have an admin dashboard where 
- owners will be able to
	- add/view/edit/delete products
	- add/view/edit/delete categories
	- publish lists (or weekly products)
	- view orders
	- make configuration changes
	- etc.
- customers will be able to
	- view products available (on this week's list) for purchase
	- add products to the cart
	- place orders

Most users will use the site on mobile, so the website should be mobile first.
